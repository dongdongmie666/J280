# J280 FPGA 旋转倒立摆控制器

基于 Gowin FPGA 和 Verilog 实现的旋转倒立摆控制工程，面向 J280 实验平台。控制链路直接在 FPGA 中实现，包含角度采集、编码器解码、自动起摆、角度 PID、位置外环、运动轨迹规划和串口观测。

目标器件为 **GW2A-LV55PG484C8/I7**，系统时钟 **50 MHz**，顶层模块为 `balance_top`。

> 本文按当前 RTL 整理。控制增益、方向和引脚绑定与现有机构有关，移植时需要重新确认。仓库中的历史验证记录对应各自版本，不代表当前源码已经完成全部回归或实机验证。

## 功能

- **自动起摆与平衡交接**：脉冲起摆，结合角度、运动速度和连续采样判定进入平衡控制。
- **串级控制**：位置外环生成目标倾角，角度内环生成电机 PWM。
- **位置保持与相对定位**：支持 30°、45°、60°、90°、120°、135°、180°、270°和 360°运动命令。
- **循环运动**：DIP1 选择正弦往返轨迹，DIP2 选择慢速前进、端点停留、较快返回的往返轨迹。
- **定点运算与流水线**：使用 Q8、Q12、Q16 等格式实现控制与单位换算。
- **在线调参**：串口调整两环 PID 增益，支持运行中修改。
- **数据观测**：921600 baud、8N1，输出 CSV 格式的角度、位置、速度、控制量和停机快照。
- **保护逻辑**：硬件停止、串口停止、ADC 数据超时、平衡阶段 ADC 过量程与倾角保护；编码器错误停机可配置。

## 控制结构

```text
串口定位命令 / 拨码循环轨迹
              │
              ▼
          目标位置 ──┐
                    ▼
编码器 1 ──────► 位置外环（10 ms）
                    │ 目标倾角
                    ▼
10 位 ADC ────► 角度内环（3 ms）
                    │ 带符号占空比
                    ▼
              20 kHz PWM ──► B 路电机驱动

自动起摆状态机 ──► 起摆期间直接驱动，满足抓取条件后交接角度环
串口数据输出 ◄── 采集、控制及停机快照
```

位置环接入前，角度环以直立位置为目标。满足直立角度与速度窗口条件后，在接入时刻捕获编码器参考位置，再逐渐增加位置环作用。编码器 AB 解码始终按系统时钟运行。

## 硬件与接口

需要 J280 对应 FPGA 板、倒立摆机构、电机驱动、10 位并行角度 ADC、正交编码器和支持 921600 baud 的 USB 转 TTL 串口适配器。使用 Gowin Programmer 下载位流。

当前顶层使用 **B 路电机驱动 + 编码器 1**；A 路驱动固定关闭。编码器 2 保留解码通路，不参与当前位置反馈。

| 接口 | FPGA 信号 / 引脚 | 说明 |
| --- | --- | --- |
| 系统时钟 | `clk_50m` / M19 | 50 MHz |
| 复位 | `rst_n` / AB3 | 低有效 |
| 串口 | `uart_tx` / K20，`uart_rx` / L20 | 3.3 V TTL，TX/RX 交叉连接，共地 |
| 电机 B | `PWMB` / V14，`BN1` / AA17，`BN2` / V15 | 当前电机输出 |
| 编码器 1 | `enc1_a` / Y20，`enc1_b` / AA20 | 当前位置反馈 |
| 编码器 2 | `enc2_a` / W18，`enc2_b` / W17 | 辅助观测通路 |
| ADC | `adc_clk` / G18，`adc_oe_n` / H20，`adc_otr` / F18 | 数据线完整绑定见 `src/balance.cst` |
| 按键 | SW1 / T18，SW2 / R18，SW3 / U20，SW4 / T20 | 低有效 |
| 拨码 | `dip1_n` / W20，`dip2_n` / V20 | 低电平为开启 |

按键与拨码 IO 使用 **LVCMOS15**；串口、电机、编码器和 ADC 等接口使用 **LVCMOS33**。接线必须匹配开发板原理图与 IO Bank 电压，不能将按键 IO 当作 3.3 V 输入使用。串口使用 TTL 电平，不能直接接 RS-232 电平。

当前电机映射为正控制量驱动 `BN2`、负控制量驱动 `BN1`。改变接线或编码器方向后，应重新检查反馈方向。

## 构建与下载

### Gowin IDE

1. 安装支持 GW2A-55C 的 Gowin EDA 与下载器驱动。
2. 打开仓库根目录的 `j280_balance.gprj`。
3. 确认器件为 `GW2A-LV55PG484C8/I7`，顶层模块为 `balance_top`。
4. 检查 `src/balance.cst` 与实际硬件一致，并按 `build.tcl` 设置 `use_sspi_as_gpio=1`。
5. 执行综合、布局布线与位流生成，查看时序及资源报告。
6. 使用 Gowin Programmer 下载生成的 `impl/pnr/j280_balance.fs`。

### 命令行

在工程根目录运行；`gw_sh` 需已加入 PATH，否则使用其实际安装路径：

```powershell
gw_sh .\build.tcl
```

`build.tcl` 会打开工程、指定顶层、启用 SSPI 引脚作为 GPIO，然后执行 `run all`。

`balance.sdc` 当前只定义了 20 ns 系统时钟。ADC 外部接口的输入延迟、板级时序仍需根据器件手册和硬件连接验证；内部时序通过不能替代接口验证。

## 快速使用

1. 固定底座，检查供电、机构活动范围、编码器和 ADC 接线，确保 SW2/SW3 可随时按下。
2. 将 DIP1、DIP2 都关闭，打开串口：**921600 baud、8 数据位、无校验、1 停止位、无流控**。
3. 使用 ASCII 字符发送命令，建议关闭自动追加换行。复位后控制器保持停机。
4. 发送小写 `w`，或在停机时按 SW1，启动自动起摆。
5. 起摆捕获后进入角度控制；等待 CSV 中 `POS_READY=1` 再发送定位命令。
6. 发送小写 `n`，目标从命令到达时的实际位置向正方向移动约 90°，完成后保持。运动中再次发送命令也从当时实际位置重新规划。
7. 按 SW2 / SW3，或发送小写 `s` / 空格停止。**SW1 在运行时是定位键，不是停止键。**

`w` 会恢复两环默认增益；需要使用自定义增益时，应注意发送顺序。当前默认 PWM 上限为 90%，自动起摆要求设置上限至少为 50%；起摆首段会直接输出脉冲。

## 命令与按键

所有串口命令均为单个 ASCII 字符，大小写有区别。

### 运行和定位

| 输入 | 动作 | 条件 |
| --- | --- | --- |
| `w` / SW1 | 自动起摆，恢复默认两环增益 | 停机时 |
| `b` | 手动进入平衡控制 | 停机；需设置极性且通过姿态、数据等检查 |
| `s` / 空格 | 停止 | 随时 |
| SW2 / SW3 | 硬件停止 | 随时；直接门控电机输出 |
| `n` / SW1 | 正向相对定位 90° | 位置环已接入，且无拨码轨迹请求 |
| `t` / `f` / `y` | 正向相对定位 30° / 45° / 60° | 同上 |
| `u` / `r` / `e` | 正向相对定位 120° / 135° / 180° | 同上 |
| `h` / `g` | 正向相对定位 270° / 360° | 同上 |
| `z` / SW4 | 清零两路编码器计数与错误计数 | 停机时 |

默认 `COUNTS_PER_REV=1040`，90°对应 260 计数。其他角度按一周计数换算并取整。该参数代表输出轴每转的实际解码计数，应结合减速比、编码器线数和四倍频解码校准。

### 拨码循环轨迹

| DIP1 | DIP2 | 模式 |
| --- | --- | --- |
| 关 | 关 | 串口 / SW1 单次定位 |
| 开 | 关 | 270°正弦往返轨迹 |
| 任意 | 开 | 270°非对称往返轨迹，DIP2 优先 |

循环轨迹在位置环接入后运行，与串口定位共用运动规划和 PID 通路。正弦轨迹单程规划时间默认约 10.24 s；DIP2 前进约 15.36 s、返回约 10.24 s，端点停留参数为 2 s，实际还受到位与稳定条件影响。

关闭拨码会取消后续循环调度，已接受的当前运动会继续完成；需要立即停止时使用 SW2/SW3、`s` 或空格。

### PID 调参

以下命令允许在运行中使用，复位后恢复初值。增益是当前离散实现中的系数，积分与微分已包含采样周期的影响。

| 参数 | 增大 / 减小 | 每次实际变化 | 默认值 |
| --- | --- | --- | --- |
| 角度 Kp | `P` / `p` | 32/256 = 0.125 | 960/256 = 3.75 |
| 角度 Ki | `I` / `i` | 1/256 = 0.00390625 | 5/256 = 0.01953125 |
| 角度 Kd | `D` / `d` | 32/256 = 0.125 | 8192/256 = 32 |
| 位置 Kp | `A` / `a` | 1/4096 = 0.000244140625 | 34/4096 = 0.00830078125 |
| 位置 Ki | `J` / `j` | 1/4096 = 0.000244140625 | 0 |
| 位置 Kd | `V` / `v` | 1/256 = 0.00390625 | 729/256 = 2.84765625 |

`k`、`l` 为两组实验预设：角度 Kp=960/256、Ki=5/256、Kd=20800/256；位置 Ki=0、Kd=729/256，位置 Kp 分别为 123/4096、132/4096。它们会同时覆盖六个增益。

以下设置仅在停机时接受：

| 命令 | 设置 |
| --- | --- |
| `+` / `-` | 正常 / 反向控制极性，主要用于手动平衡调试 |
| `O` / `o` | 开启 / 关闭位置环 |
| `c` / `C` | 开启 / 关闭启动助推 |
| `1`～`9` | PWM 上限依次为 5%、10%、15%、20%、25%、30%、35%、40%、45% |
| `0` | PWM 上限 90% |

## 串口数据格式

当前顶层设置 `COMPACT=1`，输出 **34 列 CSV**，无字段名表头，以 CRLF 结束一行。以下表头供上位机解析使用，固件不会自动发送它：

```csv
SEQ,ANGLE,POS,ENC1,OUT,PWM_TARGET,TGT_ANGLE,ANG_RATE,I_TERM,POS_KP,POS_KD,POS_TARGET,POS_READY,POS_ACT,POS_SET,POS_P,POS_D_RAW,POS_D_LIM,POS_KI,POS_I,ANGLE_KP,ANGLE_KI,ANGLE_KD,SPEED_SET,SPEED_ACT,ADC_RAW,ADC_MEAN,RUNNING,FAULT,STOP_REASON,STOP_ADC,STOP_AGE,STOP_FLAGS,STOP_ENCODER
```

| 字段 | 含义 / 单位 |
| --- | --- |
| `SEQ` | 上报触发序号，可用于观察间隔或跳帧 |
| `ANGLE`、`TGT_ANGLE` | 实测倾角、已应用目标倾角，单位 ° |
| `POS` | 相对当前位置目标的误差，编码器计数 |
| `ENC1`、`POS_ACT`、`POS_SET` | 编码器绝对计数、实际位置、目标位置，采用相同绝对坐标；单次定位时 `POS_SET` 显示终点，拨码轨迹时显示当前规划点 |
| `POS_TARGET` | 相对捕获参考点的位置命令，编码器计数 |
| `POS_READY` | 1 表示位置环已接入且可接受定位 |
| `OUT`、`PWM_TARGET` | 实际施加、目标 PWM，带符号百分比 |
| `ANG_RATE` | 未经 D 低通的实测角速度，°/s |
| `I_TERM` | 角度积分支路输出，PWM 百分比 |
| `POS_P`、`POS_D_RAW`、`POS_D_LIM`、`POS_I` | 位置环各分量，目标角度单位 ° |
| `POS_KP`、`POS_KI`、`POS_KD` | 位置环增益；Kp、Ki 显示六位小数 |
| `ANGLE_KP`、`ANGLE_KI`、`ANGLE_KD` | 角度环增益 |
| `SPEED_SET`、`SPEED_ACT` | 目标、实际输出轴角速度，°/s；无效时输出 `N/A` |
| `ADC_RAW`、`ADC_MEAN` | ADC 原始值、均值，0～1023 |
| `RUNNING`、`FAULT` | 运行标志、故障 / 启动拒绝原因码 |
| `STOP_REASON`、`STOP_ADC`、`STOP_AGE`、`STOP_FLAGS`、`STOP_ENCODER` | 首次停机原因与对应快照；`STOP_AGE` 单位为系统时钟周期 |

上报触发周期默认 3 ms。发送器忙时不会接受新的快照，因此实际整行输出频率受行长与 UART 带宽限制，不能将每一行都视为严格间隔 3 ms。PWM 换向时有一个完整 PWM 周期的零输出空白期，`OUT` 与 `PWM_TARGET` 可能不同。

停机快照原因码：`3`=ADC 过量程，`4`=数据超时，`5`=倾角超限，`7`=编码器错误，`9`=硬件停止，`12`=串口停止，`0`=尚未记录。首次停机快照保持到下一次启动请求或复位。

## 主要参数与保护边界

| 项目 | 当前设置 |
| --- | --- |
| ADC | 25 MHz 时钟；16 点均值，每 3 ms 更新 |
| 角度标定 | 直立零点 535；每码 22086/65536 ≈ 0.337006° |
| 角度控制周期 | 3 ms |
| 位置控制周期 | 10 ms |
| 位置环接入 | 直立误差不超过 14 码且 30 ms 速度窗口合格，连续 5 次新采样满足条件 |
| 位置环渐入 | 500 ms |
| 位置目标角度总限幅 | `POSITION_ANGLE_LIMIT_Q8=12800`，即 ±50° |
| 位置 P/I 目标限速 | 参数 40°/s；3 ms Q8 量化后约 39.0625°/s |
| 位置 D 支路 | 30 ms 速度窗口，独立限幅 ±4° |
| 角度 D 支路 | 对实测角度差低通：`y[k]=(5*y[k-1]+3*dx[k])/8` |
| 角度积分 | 误差死区参数 750 mdeg，死区内保留积分；积分贡献独立限幅 ±5% |
| PWM | 20 kHz，硬限幅 ±90%，换向空白一个周期 |
| 速度观测 | 编码器 50 ms 窗口估计实际转速 |
| ADC 数据超时 | 10 ms；起摆首段脉冲期间豁免 |
| 平衡倾角保护 | 相对当前目标 ADC 偏差超过 ±148 码，约 ±49.88° |
| 编码器错误停机 | `ENCODER_FAULT_PROTECTION=0`，默认关闭；仍记录解码错误 |

自动起摆抓取与位置环接入是不同判定：`swing_up.v` 当前抓取角度范围为零点 ±35 码（约 ±11.80°），并检查速度窗口及连续有效采样。掉落或保护触发后保持停机，需要重新发送 `w` 或按 SW1 起摆。

上述目标角度限幅是数值边界，不表示机构能在整个角度范围稳定。当前没有启用机械行程自动停机；运行时应保证活动空间、可靠固定和可用的停止通路。

## 仿真验证

安装 ModelSim / Questa，并将脚本参数指向包含 `vlib.exe`、`vlog.exe`、`vsim.exe` 的目录。以下在工程根目录运行：

```powershell
# 执行脚本默认回归；按本机安装位置替换工具目录
.\test_modelsim.ps1 -SimulatorBin 'C:\Tools\ModelSim\win64'

# 指定测试，例如定位与串口数据输出
.\test_modelsim.ps1 -SimulatorBin 'C:\Tools\ModelSim\win64' -Tests position_step,step_io,text

# 积分保护相关测试
.\test_integral_guard.ps1 -SimulatorBin 'C:\Tools\ModelSim\win64'

# 使用 Icarus Verilog 执行基础测试；可传绝对工具路径
.\test.ps1 -Iverilog 'iverilog' -Vvp 'vvp'
```

ModelSim 日志输出到 `build/modelsim/`。脚本检查仿真退出码、错误信息及 `PASS` 标记。默认测试集合见 `test_modelsim.ps1`，不会自动运行 `tests/` 中的全部测试；部分测试保留历史参数预期，新增功能或参数变化后需要核对相应断言。

`test_reference_netlist.ps1` 面向历史参考网表，使用前需确认网表、端口和工具路径匹配。RTL 仿真不包含完整机械动力学，不能替代实机平衡、抗扰和板级接口验证。本文更新未重新运行综合、仿真或硬件测试。
